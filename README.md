# qr-zacepi

Мобильная карточка «Зацепи Кофе» на HTML, CSS и JavaScript. Сборка, сервер, Python, Node.js и вход в ChatGPT для использования не нужны. Все ресурсы находятся в репозитории; внешних CDN и API нет.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/(root)**.
- Нажмите **Save** и дождитесь завершения публикации.

После успешной публикации адрес: https://dibil2705.github.io/qr-zacepi/

Файл `.nojekyll` отключает обработку Jekyll. Все пути к ресурсам относительные, поэтому приложение работает в подпапке `/qr-zacepi/`.

## Использование

Нажмите «⋯» справа вверху, чтобы создать новый QR и число под ним. Крестик скрывает карточку; кнопка «Открыть карту» возвращает её. Последний код восстанавливается при следующем открытии.

Диапазон включительно: **10000010100–10000161013**, всего **150 914** чисел. Используется перестановка диапазона без повторов. Параметры и счётчик сохраняются в IndexedDB; одновременная генерация в нескольких вкладках сериализуется транзакциями. Новый код появляется только после успешного сохранения. После исчерпания диапазона или при повреждении истории генерация останавливается.

Уникальность действует в рамках одного браузера, профиля и адреса сайта при сохранении его данных. Очистка данных, инкогнито, другой браузер или устройство создают независимую историю. У версии на GitHub Pages своя история, отдельная от ранее опубликованного сайта и локального файла; повторы между этими версиями не исключены.

## Файлы

- `index.html` — страница.
- `style.css` — мобильное оформление.
- `app.js` — весь JavaScript, включая библиотеку генерации QR.
- `card.png` — предоставленный скриншот.
- `QR-LICENSE.txt` — MIT-лицензия библиотеки node-qrcode.

QR соответствует параметрам исходного Python-скрипта: версия 1, коррекция M, маска 2, рамка 4 модуля. В QR записывается только число, без знака «+» или других префиксов.

Карточка использует статичные имя, баланс, дату и бонус со скриншота. Приложение не подключается к системе лояльности и не проверяет номера.
